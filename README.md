# Dominik Lentrodt - Professional Portfolio

A modern, responsive website showcasing the professional journey from academia to industry.

## 🌟 Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **GitHub Pages Compatible**: Static HTML/CSS/JS - no build process required
- **SEO Optimized**: Meta tags and structured content for search engines
- **Interactive**: Smooth scrolling, mobile navigation, and contact form
- **Fast Loading**: Optimized assets and efficient code

## 🚀 Live Website

Visit the live website at: [https://dlentrodt.github.io](https://dlentrodt.github.io)

## 🔧 Customization

To customize this website:

1. **Personal Information**: Update the content in `index.html`
2. **Styling**: Modify colors, fonts, and layout in `assets/css/style.css`
3. **Functionality**: Add or modify features in `assets/js/script.js`
4. **Images**: Replace placeholder icons with your own images

## 📧 Contact Form

The contact form is currently set up for demonstration. To make it functional:

1. Use a service like Formspree, Netlify Forms, or EmailJS
2. Update the form action in the JavaScript file
3. Add proper form validation and submission handling

## 🚀 Deployment

This website is designed for GitHub Pages hosting:

1. Push your changes to the repository
2. GitHub Pages will automatically deploy the site
3. The site will be available at `https://[username].github.io`
